# Contributing to Vehicle Pass Tracker

We love your input! We want to make contributing to Vehicle Pass Tracker as easy and transparent as possible.

## Development Process

1. Fork the repo
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Run tests (when available)
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Testing Your Changes

1. Test with different image sequences
2. Verify output CSV format remains consistent
3. Check visualization
4. Test with different camera positions if data available

## Code Style
- Follow PEP 8 guidelines
- Add type hints to new functions
- Document new functions and classes
- Keep the code modular and maintainable

## Pull Request Process

1. Update the README.md with details of changes if needed
2. Update the requirements.txt if you add dependencies
3. The PR will be merged once you have the sign-off

## Bug Reports and Feature Requests

Please use the GitHub issues tracker to:
- Report bugs
- Suggest features
- Submit pull requests

## Questions?

Feel free to contact the maintainers for any questions.
