# Contributing

## Development Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Run tests (when available)
5. Commit your changes (`git commit -m 'Add feature'`)
6. Push to the branch (`git push origin feature/your-feature`)
7. Open a Pull Request

## Testing Your Changes

1. Test with different image sequences
2. Verify output CSV format remains consistent
3. Check visualization output
4. Test with different camera positions if data is available

## Code Style

- Follow PEP 8 guidelines
- Add type hints to new functions
- Document new functions and classes
- Keep the code modular and maintainable

## Pull Request Process

1. Update README.md with details of changes if needed
2. Update requirements.txt if you add dependencies
3. The PR will be reviewed and merged after approval

## Bug Reports and Feature Requests

Use the GitHub issues tracker to:
- Report bugs
- Suggest features
- Submit pull requests

## Questions

Contact the maintainers for questions.
